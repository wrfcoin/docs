# WRFCoin Wiki

This wiki is the maintained knowledge layer for the WRFCoin protocol and its development environment. It is separate from the Heifer Zephyr instrument wiki and is tied to the Linux-side WRFCoin repo at `~/wrfcoin/`, the whitepaper at `./`, the sprint operating tooling, and the audit/CI surface.


## Status refresh (2026-09-20)

The root [implementation-status matrix](../STATUS.md) is the first stop for
current versus planned capabilities. Repository implementation, pinned private
deployment state, and public reachability are separate claims.

## Source Streams

The wiki's curated pages sit on top of these raw source streams:

- `wrfcoin-wiki` — this wiki.
- `core4-docs` — `core4/docs/` raw platform documentation.
- `audits` — `docs/audit/` audit reports.
- `sprint-handoffs` — `docs/plans/` sprint persona handoffs.

Additional source streams that haven't yet been indexed but should be on the next ingest plan: testnet operations guides, CI workflow definitions, GitHub issues/PRs, release notes, the core4 Rust workspace itself for in-code documentation.

## Library Bridge

The docs repo has a generated `site/library.html` library bridge generated by `scripts/generate_library.py`. It reads this wiki's `wiki/data/wiki-manifest.json` and reports current wiki coverage (page count by status, total sources cited, total open questions). Run `python3 wiki/scripts/generate_wiki_manifest.py --wiki-root wiki --output wiki/data/wiki-manifest.json` after any ingest, then re-run the library generator to refresh the site surface.
